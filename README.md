One letter, U, for a day that went unhinged. The program writes exactly one character — "U", no newline — to `/output/entry.txt`. Behind the letter sits the word "unhinged": a day that came off the rails, vivid, funny and true, with U as its perfect, un-obvious initial.

## Run it

```sh
python3 main.py
```
